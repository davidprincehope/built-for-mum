## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Gmail API → Worker | Enumerated via messages.list/history.list; spoofed IDs still hit processEmail dedup gate |
| Pub/Sub → Worker POST /gmail/pubsub | Push envelope is attacker-controllable if endpoint public; Phase 1 logs envelope and requires 200 ACK discipline to avoid redelivery storm |
| Worker → Postgres checkpoint | historyId and poll after cursors must advance only after success to prevent data loss on crash |
