| sendDocument chatId routing | Must be authenticated chat only |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-15 | Tampering | Search intent JSON SQL injection | critical | mitigate | Never interpolate AI strings; compile to parameterized $1::text $2::numeric $4::date etc.; validate via zod/isValid before bind |
| T-02-16 | Information Disclosure | Export leaks full raw_email or sender_account | medium | mitigate | Export columns are whitelisted (amount,currency,date,sender,description,branch,balance) never raw_email or sender_account raw; description via extractSender |
| T-02-17 | Tampering | CSV formula injection (leading = +cmd) | low | accept | CSV opens in Sheets with quoting; leading = kept quoted as "=..."; risk low single-admin; alternative prefix sanitized — accepted with note |
| T-02-18 | Denial of Service | Search query burns OpenRouter on every request | medium | mitigate | 10/60s search rate limit per chat; null API key → local keyword fallback with zero AI cost |
| T-02-19 | Tampering | sendDocument token leak via logs | medium | mitigate | Token never logged; fetch URL base redacted in pino; caption truncated 1024; chatId only |
| T-02-20 | Repudiation | Export/summary without audit | low | mitigate | pino info logs chatId + export range + row count for audit, no PII |
