<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Telegram cloud → POST /telegram/webhook | Untrusted inbound update; X-Telegram-Bot-Api-Secret-Token is only authenticity mechanism |
| Telegram user text/caption → /login, /balance, /history parsing | Untrusted input; password timing, date parse, HTML rendering are attack surfaces |
| Postgres transactions → reply formatting | Trusted DB but mis-indexed LIKE or raw interpolation would leak/infer |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-01 | Spoofing | POST /telegram/webhook without secret header | critical | mitigate | verifySecretToken timingSafeEqual on lowercased x-telegram-bot-api-secret-token before body parse; 403 no DB touch; worker.ts:313 pattern |
| T-02-02 | Spoofing | Brute-force /login password | high | mitigate | timingSafeEqual compare, login 5/60s per-chat sliding window, generic Wrong password no echo, pino redact paths for TELEGRAM_BOT_PASSWORD |
| T-02-03 | Tampering | /history date args SQL injection | high | mitigate | Parameterized $1::date BETWEEN query; date-fns parse + isValid validation before binding; never interpolate args |
| T-02-04 | Tampering | /balance, /history HTML injection via sender_name/description | medium | mitigate | escapeHtml all DB/user strings before HTML parse_mode; fallback retry without parse_mode on 400 can't parse entities (sendMessage.ts:89-93) |
| T-02-05 | Information Disclosure | Log leakage of passwords/tokens | high | mitigate | logger redact remove:true for TELEGRAM_BOT_PASSWORD, TELEGRAM_WEBHOOK_SECRET, TELEGRAM_BOT_TOKEN, OPENROUTER_API_KEY, DATABASE_URL, GOOGLE_REFRESH_TOKEN |
| T-02-06 | Denial of Service | Rate-limit bypass via bursts on /balance,/history,/login | medium | mitigate | Sliding-window Map<chatId:command, number[]> global 15/10s + per-command stricter limits; 200 OK always, no throw |
| T-02-07 | Elevation of Privilege | Session fixation / never-expiry via Map | medium | mitigate | 24h TTL checked on every gated command, hourly sweep unref, logout clears, restart requires re-login with explicit hint |
| T-02-SC | Tampering | npm install pdf-parse (only new dep, not in this plan) | high | mitigate | Package Legitimacy gate — this plan installs nothing; pdf-parse install deferred to 02-02 with registry verification |
</threat_model>
